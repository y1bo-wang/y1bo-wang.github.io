# Yibo Wang academic homepage

This is a static site. It has no package installation or build step.

## Run locally

Open `index.html` in a browser, or from the project directory run:

```powershell
python -m http.server 8765
```

Then visit <http://127.0.0.1:8765/>.

## Publish with GitHub Pages

Push this repository to GitHub, then open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. This user site is available at:

<https://y1bo-wang.github.io/>
